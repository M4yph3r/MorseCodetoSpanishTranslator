# 📡 Traductor de Código Morse

Aplicación web desarrollada en HTML, CSS y JavaScript que permite convertir texto en español a código Morse y viceversa.

## Funcionalidades

- Conversión de texto a código Morse.
- Conversión de código Morse a texto.
- Interfaz simple y fácil de utilizar.
- Funciona directamente en el navegador.
- Compatible con GitHub Pages.
- No requiere instalación de dependencias.

---

## Cómo utilizar

### Español - Morse

1. Escriba un texto en la sección **Español → Morse**.
2. Pulse el botón **Traducir**.
3. El resultado aparecerá en la caja inferior.

### Morse - Español

1. Ingrese el código Morse en la sección **Morse → Español**.
2. Separe cada letra con un espacio.
3. Separe cada palabra con tres espacios.
4. Pulse el botón **Traducir**.
5. El resultado aparecerá en la caja inferior.

### Ejemplo

Texto:

```text
hola mundo
```

Resultado Morse:

```text
.... --- .-.. .-   -- ..- -. -.. ---
```
